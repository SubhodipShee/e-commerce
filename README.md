# ⚡ ElectroPlaza  

ElectroPlaza is a full-stack **e-commerce website for electronics**, built with the MERN stack (MongoDB, Express.js, React, Node.js).  
It provides a smooth shopping experience for users and a powerful admin panel for managing products.  

---

## 🌟 Features  

### 👨‍💻 User Side  
- Browse electronic products with images and details  
- Search and filter products  
- Add items to cart  
- Secure authentication (sign up / login)  
- Checkout flow (cart management, order summary)  

### 🛠️ Admin Side  
- Add, update products  
- Manage product details and pricing  
- Upload product images  
- Monitor product catalog in real-time  

---

## 🏗️ Tech Stack  

- **Frontend:** React.js, React Router,Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas or Local)  
- **Authentication:** JWT / Cookies  
- **Other:** Cloudinary / Multer (for product images), REST APIs  

---
